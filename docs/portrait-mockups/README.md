# Faction portrait mockups

Open `index.html` to compare three faction directions in the established naval-portrait presentation:

1. **Lyr Command** — cold cyan, formal fleet hierarchy.
2. **The Unbound** — green-blue, practical survivor ensemble.
3. **Pirate Pact** — hot red, confrontational captains.

These are art-direction mockups assembled from the licensed portrait set already shipped with the prototype; character assignments can be revised once the final story document is available in the repository.
